# PHP

Este repositório contém códigos práticos em PHP desenvolvidos exclusivamente para fins de estudo, aprendizado e testes de lógica de programação (como estruturas de repetição, condições e Orientação a Objetos).
Para rodar e testar qualquer um desses códigos diretamente na sua máquina, você não precisa instalar nenhum servidor local (como XAMPP ou Docker). 
Basta seguir o passo a passo abaixo:
Acesse o GDB Online (onlinegdb.com) — a IDE web onde estes códigos foram desenvolvidos e testados.
No canto superior direito da tela, mude a opção "Language" para PHP.
Baixe ou copie o código do arquivo desejado aqui do repositório.
Cole o código no editor do GDB Online e clique no botão "Run" (ou aperte F9) para ver o resultado rodando na hora.
